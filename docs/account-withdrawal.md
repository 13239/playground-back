# 본인 회원탈퇴

프로필 모달 하단 왼쪽의 테두리 없는 ‘회원탈퇴’ 문구로 확인 창을 연다. 현재 비밀번호를 입력하고 최종 회원탈퇴 버튼을 눌러야 요청한다. 취소하면 프로필 모달과 저장하지 않은 캐릭터 선택을 유지한다. 프로필·닉네임 저장 중에는 탈퇴를 시작하지 않고, 탈퇴 확인 중에는 부모의 저장·닫기를 막는다. 탈퇴 제출 중에는 중복 제출·취소·Escape 닫기를 막는다.

## 요청과 처리

- 브라우저와 Spring은 POST `/api/auth/withdrawal`을 사용한다. 브라우저 본문은 `sessionId`, `currentPassword`만 허용하며 Spring에는 비밀번호만 전달한다. 대상 회원은 인증된 `Session.id`에서 정한다.
- 기존 Origin·BFF 서버 인증·JWT·Redis 세션·브라우저 증명을 적용한다. BFF는 화면의 세션 ID와 쿠키의 세션 ID를 대조하며 다른 탭에서 바뀐 로그인에 이전 화면의 탈퇴를 적용하지 않는다.
- 계정당 분당 5회로 제한한 뒤 회원 행 잠금을 얻는다. 현재 활성·미삭제 계정인지 검사하고 ROOT를 보호한다. 잠금을 기다리는 동안 종료된 세션인지 다시 확인한 뒤 현재 비밀번호를 대조한다.
- 기존 `UserService.withdraw`로 모든 세션과 신규 로그인을 먼저 차단하고 상태를 WITHDRAWN으로 변경한다. `deleted_at`은 수정하지 않는다. 물리 삭제·소프트 삭제 기능을 추가하지 않는다.
- 기존 트랜잭션·커밋 이후 활동 로그 경로로 WITHDRAWAL을 기록한다. 로그와 브라우저 저장소·URL·오류 응답에 비밀번호를 넣지 않는다. 증명 본문 해시에서도 비밀번호를 제외하고 세션 ID만 결합한다.
- 성공 응답은 204와 no-store다. 실제 성공한 경우에만 BFF 인증 쿠키를 지운다. 브라우저는 로그인·갱신과 같은 탭 잠금 안에서 요청을 완료한 뒤 인증 변경을 다른 탭에 알리고 `/login`을 새 문서로 연다.
- 비밀번호 오류·세션 불일치·서버 장애에는 쿠키를 임의로 지우지 않는다. 업무 오류·네트워크 장애로 변경 요청을 자동 재전송하지 않는다. 인증 필터가 실행 전에 거절한 경우만 기존 인증 갱신 후 한 번 재실행한다.

기존 `status VARCHAR(10)`과 활동 로그의 `activity_type VARCHAR(40)`을 사용하므로 추가 DB 마이그레이션은 없다. 프론트·백엔드를 함께 반영하고 실행 중인 백엔드를 재시작한다.

## 구현 위치

- `domain/user/controller/UserWithdrawalController`: 본인 API 진입점과 204 응답.
- `domain/user/service/UserWithdrawalService`: 현재 비밀번호·행 잠금·세션 재검증·요청 제한과 활동 기록.
- `domain/user/dto/request/WithdrawAccountRequest`: 비밀번호만 받는 builder DTO.
- 프론트 `src/app/api/auth/withdrawal/route.ts`: Origin·입력·화면 세션 검증과 성공 후 쿠키 정리.
- 프론트 `src/features/profile/components/withdrawal-dialog.tsx`: 확인·비밀번호 입력·오류·처리 중 잠금과 로그인 이동.
- 프론트 `src/features/profile/components/profile-editor.tsx`: 하단 왼쪽 버튼과 부모/자식 모달 상태.

## 검증

실제 회원·DB·Redis를 변경하지 않는 백엔드 테스트 12개와 BFF·본문 결합·입력·클라이언트 계약 검사 18개가 통과했다. 비밀번호 오류, 종료된 세션, 다른 탭의 새 세션, ROOT, 비활성·탈퇴·삭제 계정, 요청 제한과 Retry-After, Redis·백엔드 실패, 성공 시에만 쿠키 정리, 인증 갱신 중 잠금 재진입 방지를 확인했다. 비밀번호 변경의 기존 입력 규칙도 함께 확인했다. 임시 테스트 코드와 검증 페이지는 실행 후 삭제했다.

격리된 브라우저 응답으로 하단 버튼의 테두리·위치, 비밀번호 누락/오류, 중복 제출과 처리 중 Escape 차단, 취소 후 초안·포커스 복귀, 최고 관리자 보호, 제한 응답의 즉시 재전송 방지, 성공 후 로그인 이동을 확인했다. 320·390·768·1920·2560·3840·4096px과 844×390 가로 화면에서 화면 경계·가로 넘침·하단 정렬을 확인했다. 요청한 5120px은 검증 브라우저가 4096px로 제한해 5K 실측에는 포함하지 않았다.

Java 25 실행 JAR 빌드, 프론트 전체 ESLint·TypeScript 검사와 Next.js Webpack 최적화 빌드가 통과했다. 임시 검증 경로는 최종 프론트 빌드에 포함되지 않는다.
